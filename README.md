# resKern
Rust based kernel to learn with

## Current Stable:
Release-v0.5.5

## Prior Stable (Not recommended for use):
Release-v0.5.0

## Info
Building a kernel in rust where there is no standard library to use so you have to learn a lot from scratch.

We have a security policy as well as private vulnerability reporting enabled. Please use and follow it.

Currently AGPL but this is subject to change

This project uses nightly.
